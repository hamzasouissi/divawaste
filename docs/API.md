# API

Base path `/api/v1`. JSON only. 150 routes, listed below as generated by `php artisan route:list --path=api/v1`.

## Conventions

| Topic | Rule |
|---|---|
| Identifiers | ULIDs (`ulid` field). Numeric ids are never exposed |
| Envelope | `{ "data": … }`; lists add `meta` (`current_page`, `last_page`, `per_page`, `total`) |
| Lists | `page`, `per_page` (max 100), `sort=field` or `sort=-field`, `filter[name]=value`, `filter[name][]=a&filter[name][]=b` |
| Numbers | Weights and amounts are decimal **strings** (`"42.500"`); never floats |
| Dates | ISO 8601 UTC for instants, `YYYY-MM-DD` for calendar days |
| Labels | Reference values carry every language: `{ "fr": "…", "en": "…" }` |
| Errors | RFC 9457 `application/problem+json`: `status`, `code` (stable, translatable), `detail`, `errors` (422), `request_id` |
| Business rules | HTTP 409 with a `code` such as `PROVIDER_NOT_ELIGIBLE`, `VARIANCE_NOT_ACKNOWLEDGED` |
| Read-only account | HTTP 402 `PAYMENT_REQUIRED` on writes when the subscription has lapsed |
| Files | Downloads are authorised routes returning the file; uploads are `multipart/form-data` with a `file` field |

## Authentication

- Web: `GET /sanctum/csrf-cookie`, then `POST auth/login` `{ email, password, mode: "session" }`. Send the `X-XSRF-TOKEN`
  header on writes. The answer may ask for `code` (TOTP) or `company` (several memberships).
- Token: `POST auth/login` with `mode: "token"` returns a bearer token valid 12 hours.
- `GET me` returns the user; `GET me/access` the company, roles and permissions per site.
- Routes under `platform/` need platform permissions and no company; all others act inside the signed-in company.
