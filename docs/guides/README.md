# Guides DivaWaste

Dix guides pas à pas, en français, avec des captures prises sur l'application réelle. Chaque PDF a sa source
(`guide-N/guide.html`) et ses images à côté.

Sur le serveur de démonstration, ce dossier est publié tel quel à l'adresse `/guides/` (page `index.html`) ; dans
l'application, le menu du compte (en haut à droite) propose « Guides d'utilisation ».

| Guide | Pour qui | Ce qu'il couvre |
|---|---|---|
| [1 — Créer votre compte](DivaWaste-Guide-1-Creer-votre-compte.pdf) | Industriel, premier administrateur | Inscription (et mode test : compte prêt tout de suite), secteur, mise en route avec l'assistant, paramètres, import de lots par Excel, Bourse |
| [2 — Sans ERP, avec production](DivaWaste-Guide-2-Sans-ERP-avec-production.pdf) | Industriel sans ERP | Production saisie dans DivaWaste : OF, matières, lots reçus, déchets rattachés ; chute estimée (déchets produits, efficience), tailles, coupe par matelas, estimé contre pesé |
| [3 — Avec ERP, avec production](DivaWaste-Guide-3-Avec-ERP-avec-production.pdf) | Industriel avec ERP | Import des fichiers de l'ERP, colonnes retenues, imports de nuit, API ; chute estimée (colonnes Type de déchet et Efficience), tailles et matelas saisis dans DivaWaste |
| [4 — Référence](DivaWaste-Guide-4-Reference.pdf) | Administrateur, responsable environnement | Types de déchets, autorisations de sortie, cycle de vie d'un lot (prestataire avec ou sans compte), chaque valeur de l'Accueil, trouver un prestataire dans la liste ANGed |
| [5 — Prestataire et Bourse](DivaWaste-Guide-5-Prestataire-et-Bourse.pdf) | Prestataire ; vendeur sur la Bourse | Compte prestataire, agréments, profil, Bourse côté preneur et côté vendeur |
| [6 — L'assistant virtuel](DivaWaste-Guide-6-Assistant-virtuel.pdf) | Tous | Ce que fait l'assistant, ce qu'il ne fait jamais, comment lui parler |
| [7 — Équipe, rôles et accès](DivaWaste-Guide-7-Equipe-roles-et-acces.pdf) | Administrateur ; tous pour « Votre compte » | Invitations (et lien à copier en mode test), les rôles et ce que chacun voit, rôles par site, rôles sur mesure, profil, double authentification, notifications |
| [8 — Application atelier](DivaWaste-Guide-8-Application-atelier.pdf) | Opérateur atelier | Créer, peser, ranger un lot sur téléphone, scanner, charger un enlèvement, hors ligne, l'assistant au poste |
| [9 — Le suivi au quotidien](DivaWaste-Guide-9-Suivi-au-quotidien.pdf) | Administrateur, responsable environnement | Stock et limites, enlèvements, contrats, registre, bordereaux et signature, documents, déclaration annuelle, rapports, journal d'audit, abonnement, recherche |
| [10 — Back-office](DivaWaste-Guide-10-Back-office.pdf) | Diva Software | Inscriptions, agréments, virements, formules, factures, catalogue, rôles, activité, liste ANGed, mode test |

Exemples de documents utilisés par les guides : `guide-4/declaration-douane-exemple.pdf`,
`guide-4/bordereau-signe-exemple.pdf`, `guide-5/agrement-exemple.pdf`, `guide-1/registre-lots.xlsx`,
`guide-3/erp-*.xlsx`.
