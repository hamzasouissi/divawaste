R1. Ajouter et modifier un type de déchet

Le type dit ce qu'est un déchet : son nom, sa famille, son code déchet réglementaire (celui des bordereaux et de la déclaration annuelle), s'il est dangereux, et comment on le mesure. Chaque lot porte un type.

1Le plus simple : activer un type du catalogue

Paramètres › Types de déchets, onglet Catalogue de référence, bouton Activer (Guide 1, étape 3). Tout est déjà rempli, code déchet compris.

2Rien ne correspond : un type personnalisé

  1. Dans le catalogue, cliquez sur Rien ne correspond ? Créer un type personnalisé.

  1. Remplissez :

3Modifier un type

  1. Onglet Mes types : cliquez sur le nom du type (ici Chutes de coupe). La fenêtre Modifier le type s'ouvre.
Ce qui ne change plus. Le code, la famille, le code déchet et la dangerosité sont figés après la création : les lots et les documents réglementaires s'y réfèrent. Seuls le nom, l'unité, la mesure, la filière, le conditionnement, la composition et « sous autorisation » se modifient. Pour un autre code : créez un nouveau type et désactivez l'ancien.
Désactiver (en bout de ligne) retire le type des nouveaux lots sans rien effacer. « Afficher les types désactivés » les retrouve. Type dangereux sans code ? Un bandeau « Code réglementaire manquant » propose Compléter le code : choisi une fois, il ne change plus.

R2. Les autorisations de sortie (douane)

Pour une entreprise sous régime douanier (totalement exportatrice…), certains déchets ne sortent du site qu'avec une déclaration signée par la douane : un type de déchet, une période, une quantité. DivaWaste tient le compte de ce qui est sorti et bloque un enlèvement qui dépasserait l'autorisation.

1Allumer le module

Réponse Oui à « Certains déchets sortent-ils sous autorisation de la douane ? » (mise en route), ou Paramètres › Modules et fonctionnement › Autorisations de sortie.

2Marquer les types concernés

Sur chaque type concerné, cochez « Ce déchet ne sort du site que sous autorisation » (R1). Il porte alors l'étiquette Sous autorisation.

DivaWaste · Guide 4 — Référence

3Saisir l'autorisation reçue

  1. Conformité › Autorisations, bouton Nouvelle autorisation.
  2. Commencez par le document : Joindre le document signé (PDF, JPG ou PNG). L'assistant le lit et remplit le formulaire : ici le type, la référence, les deux dates et 2 000 kg. Vérifiez chaque valeur.

À gauche : le formulaire vide. À droite : rempli par l'assistant d'après le PDF.

ChampÀ savoir

Référence *, Valable du / Jusqu'au *Comme sur la déclaration. Hors de la période, l'autorisation ne couvre rien.

✔ Vous devez voir DS-2026-0147 · Coupons de tissu · 1 nov. → 31 déc. 2026 · 2 t · Utilisation 0 kg / 2 t · « Respecté » · En vigueur.

4Ce qui se passe ensuite

  • À la demande d'enlèvement, DivaWaste affiche ce que l'enlèvement consommera : « Coupons de tissu — couvert par l'autorisation DS-2026-0147 : 300 kg / 2 t, 15 %, Respecté, Reste 1,7 t » (R3).
  • Sans autorisation en vigueur, ou si une limite serait dépassée ou ne peut être vérifiée (lot non pesé), la demande est bloquée.
  • États : En vigueur, À venir, Terminée, Retirée (décochez « En vigueur » pour la retirer).
  • Une fois utilisée, le type, la période et les quantités ne se modifient plus : saisissez une nouvelle autorisation.

Après l'enlèvement de R3 : 300 kg / 2 t utilisés, 15 %, reste 1,7 t.

1Le lot

Déchets › Lots › Nouveau lot : zone, type (ici Coupons de tissu), poids (300 kg). Créer.

DivaWaste · Guide 4 — Référence

2La demande d'enlèvement Vous

  1. Sur le lot : Demander un enlèvement (ou Enlèvements › Demandes › Nouvelle demande).
  2. Cochez les lots, choisissez le destinataire (« Sous contrat » s'il y en a un), la Date souhaitée (calendrier). Plus de détails : transporteur (le destinataire par défaut), filière prévue.
  3. Lisez les encadrés : l'autorisation consommée (R2), le contrat appliqué. Envoyer la demande.
✔ Vous devez voir ENL-2026-0001 « Demandé », et l'étape : « Recyclage du Sahel doit confirmer la date ».
DivaWaste · Guide 4 — Référence

3La confirmation Prestataire

Le prestataire voit la demande dans Demandes d'enlèvement et répond : Confirmer le 5 nov. 2026, Proposer une autre date ou Refuser.

4Le bordereau, puis le chargement Vous

  1. Établir les bordereaux de suivi : un bordereau par déchet (ici BSD-2026-0001), pré-rempli.
  2. Le jour J, Enregistrer le chargement : cochez les lots qui partent et vérifiez leur poids (Tout chargé comme déclaré). Un lot non coché retourne en stock.
DivaWaste · Guide 4 — Référence

5Signer le bordereau Vous Prestataire

Conformité › Bordereaux : chaque partie signe. Électronique (avec son mot de passe) ou À la main (sur le bordereau imprimé). Ici : vous comme producteur, puis Recyclage du Sahel comme transporteur et destinataire.

6Réception et traitement Prestataire

  1. Enregistrer la réception : le poids reçu de chaque lot (ici 296 kg pour 300 kg partis : écart −1,3 %, dans la tolérance).
  2. Déclarer le traitement : la filière réelle (ici Réutilisation).
Un écart au-delà de la tolérance du déchet est signalé : « À vous : traiter l'écart de poids à la réception » (bouton Traiter l'écart).
DivaWaste · Guide 4 — Référence

7Clôturer Vous

Bouton Clôturer, puis confirmez : les lots passent au statut « Clôturé » ; poids, filières et prix ne changent plus.

✔ Vous devez voir « Enlèvement clôturé » et Documents complets : « Tous les bordereaux sont signés par toutes les parties et archivés ». Sur le lot : les six étapes cochées, « Cycle terminé, de la production au traitement », et l'historique (qui, quand, par quel moyen).
Clôturer ne complète pas les documents. Si un bordereau n'est pas signé par tous, la page le dit : « Clôturer l'enlèvement ne complète pas ses documents ».

R4. Le même cycle, prestataire sans compte Collecte Ben Ali (collecteur)

Un prestataire sans compte ne voit rien dans DivaWaste : vous enregistrez vous-même ses réponses et ses étapes, et il signe le bordereau à la main.

ÉtapeAvec compte (R3)Sans compte (R4)
Confirmer la dateLe prestataireVous, quand il vous a répondu
Bordereau, chargementVousVous
Signatures transporteur et destinataireEn ligne, par le prestataireÀ la main ; vous saisissez qui et quand, puis le scan
Réception, traitementLe prestataireVous, d'après son bon
ClôturerVousVous

« Collecte Ben Ali n'a pas de compte : enregistrez vous-même sa réponse, la réception et le traitement des lots. »

DivaWaste · Guide 4 — Référence
  1. Confirmer le 4 nov. 2026 (sa réponse), Établir les bordereaux, Enregistrer le chargement — comme en R3.
  2. Enregistrer la réception (Tout reçu comme parti : 40 kg) et Déclarer le traitement (Recyclage) : vous les saisissez d'après le bon du collecteur.
  3. Le bordereau : imprimez-le (Ouvrir le PDF), faites-le signer, puis Enregistrer la signature pour le transporteur et le destinataire : Nom du signataire, Date de signature, votre mot de passe.
  1. Quand toutes les signatures sont saisies : Joindre l'exemplaire signé (le scan, PDF, JPG ou PNG). Il devient le document archivé.
  2. Clôturer.
✔ Vous devez voir BSD-2026-0002 « Signé », « Signé à la main par Ali Ben Ali », Voir l'exemplaire signé ; l'enlèvement « Clôturé », Documents complets.
