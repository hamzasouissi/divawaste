# Frontend Engineering Skill

Reusable Agent Skill for applying the Frontend Engineering Standard across frontend projects.

## Bundle

- `SKILL.md` — agent-facing workflow and mandatory behavior
- `references/FRONTEND_ARCHITECTURE_STANDARD.md` — canonical detailed engineering standard

## Design

The skill deliberately keeps the operational instructions concise and stores the detailed engineering rules in `references/`, so the standard can evolve independently of the agent workflow.
